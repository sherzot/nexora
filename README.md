# NEXORA

NEXORA is an AI-native Virtual Engineering Organization: specialized AI agents coordinate real software engineering work through a visual Virtual Office under human governance.

**Project state: Architecture / Design.** This foundation contains governance, Accepted ADR-001 (core language), Accepted ADR-002 (architecture style), Accepted ADR-003 (agent runtime), Accepted ADR-004 (durable orchestration), Accepted ADR-005 (event architecture), Accepted ADR-006 (memory architecture/Sophia), Accepted ADR-007 (MCP/tool architecture), Accepted ADR-008 (sandbox/execution), Accepted ADR-009 (security/isolation), Accepted ADR-010 (human approval), Accepted ADR-011 (observability/audit), and Accepted ADR-012 (deployment architecture); no application has been implemented.
